Qu'est-ce qu'une e-photo ANTS ?

L'e-photo, ou photo-signature numérique, est la version dématérialisée de la photo d'identité. Au lieu de repartir avec une planche papier à coller sur un formulaire, vous repartez avec un code. Ce code renvoie à deux fichiers déposés sur le serveur sécurisé de l'Agence nationale des titres sécurisés : votre photo et votre signature manuscrite numérisée.

Lorsque vous saisissez ce code dans votre démarche sur ants.gouv.fr, l'administration récupère directement les deux pièces. Rien à scanner, rien à envoyer par courrier, aucun risque que la photo s'abîme ou se perde dans un dossier.

Concrètement, c'est ce qui a remplacé la vieille étape « collez votre photo dans le cadre et signez dans le rectangle » pour les démarches qui se font désormais en ligne.

Pourquoi l'agrément ANTS est obligatoire

Tout le monde ne peut pas produire une e-photo. Seuls les photographes et les cabines automatiques agréés par l'Agence nationale des titres sécurisés disposent du dispositif qui dépose la photo et la signature sur le serveur de l'État et génère le code associé.

Cet agrément n'est pas une simple étiquette commerciale : il est vérifié par l'administration, et c'est lui qui garantit que votre photo sera lue et acceptée par le système. Une photo, même parfaite, envoyée en dehors de ce circuit n'a aucune valeur pour une démarche en ligne.

Le studio de Saint-Juéry est agréé : la photo, la signature et le code sont produits sur place, en une seule séance.

Repérer un professionnel agréé est simple : la vignette bleue et blanche « Photo — Signature numérisée » est affichée en vitrine ou en cabine. En cas de doute, demandez : un photographe agréé n'a aucune raison de ne pas le confirmer.

Comment ça se passe au studio

  1. Vous passez sans rendez-vous

    Sans rendez-vous pendant les horaires d'ouverture, au 23 avenue Germain Téqui à Saint-Juéry. Aucune pièce n'est nécessaire pour la prise de vue elle-même.

  2. Prise de vue et contrôle

    Éclairage professionnel, fond réglementaire, plusieurs clichés. Le cadrage, la hauteur du visage, les ombres et les reflets sont vérifiés à l'écran selon les normes en vigueur avant validation.

  3. Signature numérisée

    Vous signez sur une tablette dédiée, dans un cadre blanc. C'est cette signature qui apparaîtra sur votre titre : prenez le temps de la faire comme d'habitude, sans déborder du cadre.

  4. Remise du code

    Photo et signature sont transmises au serveur de l'ANTS, et le code vous est remis imprimé. Conservez-le : c'est lui, et lui seul, qui vaut preuve de la démarche.

Utiliser le code dans votre démarche

Le principe est toujours le même :

  1. Connectez-vous à votre démarche sur ants.gouv.fr (ou via FranceConnect).
  2. À l'étape « photo et signature », choisissez l'option photo numérique plutôt que l'envoi papier.
  3. Saisissez le code figurant sur le justificatif remis par le photographe, en respectant exactement les caractères.
  4. Le système affiche votre photo : vérifiez que c'est bien la vôtre, puis validez.

Le code est à usage unique : une fois consommé par une démarche, il ne peut pas resservir pour une seconde. Si vous avez deux titres à demander, prévoyez-le et dites-le moi, cela s'anticipe au moment de la prise de vue.

Le permis de conduire : le cas le plus fréquent

C'est de loin la première raison pour laquelle on vient chercher une e-photo. La demande de permis de conduire — première obtention, renouvellement, permis abîmé, perdu, volé, ou changement d'état civil — se fait exclusivement en ligne. Il n'y a plus de guichet où déposer une photo papier.

Sans code e-photo valide, le dossier reste bloqué à l'étape photo. Avec le code, l'étape prend trente secondes.

C'est aussi la démarche où les dossiers se font le plus souvent rejeter pour une photo non conforme envoyée par un autre canal : le passage par un photographe agréé supprime purement et simplement ce risque.

Carte d'identité et passeport : e-photo ou papier ?

Pour la carte nationale d'identité et le passeport, la pré-demande se fait en ligne mais le dépôt du dossier se fait toujours en mairie, avec prise d'empreintes. Selon les communes et l'état d'avancement de leurs équipements, on vous demandera :

  • soit le code e-photo, saisi dans la pré-demande ;
  • soit une photo papier classique, à remettre au guichet.

Le plus sûr, quand on ne sait pas : repartir avec les deux. C'est ce que je conseille pour un dossier de CNI ou de passeport, d'autant que la planche papier vous restera utile six mois pour d'autres démarches.

Durée de validité et réutilisation

  • Le code e-photo est valable six mois à compter de la prise de vue, comme une photo papier.
  • Il est à usage unique : une démarche = un code.
  • Il reste rattaché à votre identité : il n'est ni transmissible ni utilisable par un proche.
  • Passé six mois, ou après un changement d'apparence notable, il faut refaire la prise de vue.

Ce qui ne fonctionne pas

Quelques idées reçues qui coûtent du temps :

  • Un selfie ou une photo prise au smartphone : aucun code n'y est associé, donc aucune valeur pour une démarche en ligne.
  • Le scan d'une photo papier : même conforme, une image téléversée ne remplace pas le circuit sécurisé de l'ANTS.
  • Une photo prise chez un photographe non agréé : elle peut être parfaite techniquement, elle ne génère pas de code.
  • Un code périmé ou déjà utilisé : le formulaire le refusera sans ambiguïté.

Questions fréquentes

Qu'est-ce que le code e-photo exactement ?

C'est une référence à usage unique remise par un photographe ou une cabine agréés ANTS. Elle pointe vers votre photo et votre signature déposées sur le serveur sécurisé de l'État. Vous la saisissez dans votre démarche en ligne, et l'administration récupère les deux pièces directement.

Combien coûte une e-photo ANTS ?

14 € au studio de Saint-Juéry, photo et signature numériques comprises, code remis immédiatement. La planche de 6 photos papier, elle, est à 12 €. Beaucoup de personnes prennent les deux pour un dossier de carte d'identité ou de passeport.

Puis-je utiliser le même code pour mon permis et mon passeport ?

Non. Le code est à usage unique : une démarche consomme un code. Si vous avez deux titres à demander, dites-le au moment de la prise de vue, cela s'organise en une seule séance.

L'e-photo est-elle obligatoire pour le permis de conduire ?

La demande de permis se fait en ligne, et l'étape photo passe par le circuit numérique de l'ANTS. En pratique, il vous faut donc un code e-photo délivré par un professionnel ou une cabine agréés : une photo papier ou un fichier envoyé par vos soins ne permet pas de finaliser le dossier.

Mon code est refusé, que faire ?

Vérifiez d'abord la saisie : les confusions 0/O, 1/I et 5/S sont les plus fréquentes, et il ne faut ajouter ni espace ni tiret. Si le code est bien saisi, il a probablement déjà été utilisé ou il date de plus de six mois. Appelez le 07 57 81 36 40, on regarde ensemble.

Faut-il prendre rendez-vous pour une e-photo ?

Non. Le studio accueille sans rendez-vous pendant les horaires d'ouverture indiqués sur la page d'accueil, et la séance complète — prise de vue, signature, remise du code — prend environ cinq minutes.
